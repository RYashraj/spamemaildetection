## Project Description

This project trains and evaluates two text classifiers — **Multinomial Naive
Bayes** (primary) and **Logistic Regression** (baseline) — on the
[UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection)
to distinguish legitimate ("ham") from spam messages.

> **Note on dataset**: Despite the project title, the underlying dataset
> contains SMS text messages, not raw email with headers or attachments. The
> classification methodology transfers directly to email body text. See
> [`docs/data_dictionary.md`](docs/data_dictionary.md) for full details.

## Setup Instructions

### 1. Clone the repo
```bash
git clone https://github.com/RYashraj/spamemaildetection.git
cd spamemaildetection
```

### 2. Create and activate a virtual environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python -m venv venv
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Download the raw dataset
Follow the instructions in [`data/README.md`](data/README.md) to download
`spam.csv` and place it at `data/raw/spam.csv`.

### 5. Run notebooks in order
```bash
jupyter notebook
```
Open and run notebooks in numeric order:
| # | Notebook | Phase | Description |
|---|----------|-------|-------------|
| 01 | `01_data_setup_and_audit.ipynb` | Phase 1 | Data ingestion, QC, cleaning |
| 02 | _(Phase 2 — EDA)_ | Phase 2 | Exploratory Data Analysis |
| 03 | _(Phase 3 — Modelling)_ | Phase 3 | Feature engineering & training |
| 04 | _(Phase 4 — Evaluation)_ | Phase 4 | Model comparison & reporting |

## Key Design Decisions

- **`config.py`** is the single source of truth for `RANDOM_STATE`, `TEST_SIZE`,
  file paths, and `LABEL_MAP`. Import it; never hardcode.
- **Raw CSV is gitignored** — follow [`data/README.md`](data/README.md) to
  obtain the file locally.
- **No vectorisation or train-test split in Phase 1** — only the constants
  are scaffolded; execution happens in Phase 3.
